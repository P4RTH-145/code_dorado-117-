Cloud Synchronization & Multi-Device Access

Configure Supabase PostgreSQL so student accounts created here can log in from any phone, laptop, or other computer.

Why couldn't students log in on other devices?

  1. Local Storage vs Cloud: Without an active Supabase API key, StudySync runs in Local Device Mode where student accounts are saved only in this device's browser (IndexedDB).
  2. To enable cross-device login: Enter your Supabase Project URL and Anon Public Key. Once connected, accounts are stored in the cloud PostgreSQL database and sync to all devices instantly.
  3. Offline alternative: Click "Export All Data (JSON)" here, send the file to the other device, and click "Import Data (JSON)".
